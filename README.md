# 다람이의 도토리 숲 · 7차 개발

월급 → 예산 → 적금 → 복리 → 주식 첫걸음 → 카드 → 돌발 상황 → 장기 전망 → 재무계획서 순서의 교육용 도트 RPG입니다. 6차를 플레이한 학생 23명의 피드백(학생피드백.pdf)을 반영했습니다. 미션 내용·채점·계산 가정은 6차와 같습니다.

## 7차 변경: 학생 피드백 반영

### 진행 버그 수정
- **미션이 저절로 엔딩까지 넘어가던 버그**: 지도 화면의 「텍스트 학습 · 현재 미션」 버튼을 누르면 텍스트 모드로 바뀌어, 이후 미션이 연달아 열렸습니다. 지도에서 이 버튼을 없앴고, 텍스트 학습은 시작 화면에서만 고를 수 있습니다.
- **스페이스·엔터가 화면 버튼을 다시 누르던 문제**: 창을 닫으면 초점을 지도로 돌립니다.
- **답을 맞혔는데 못 넘어가던 문제**: 답을 고르면 다음에 눌러야 할 곳(재도전, 바구니 실험, 미션 완료 버튼)으로 화면이 자동으로 이동합니다. 미션 화면 아래에 「다음 할 일」 안내가 항상 보입니다.
- **미션 중 재시작 버튼**: 모든 미션 화면 아래에 있던 「새 학생 시작 · 데이터 삭제」를 빼고, 📒 기록의 선생님용 칸으로 옮겼습니다.

### 다시 보기·복습
- **📒 기록**: 끝낸 미션마다 처음 고른 답, 점수, 재도전 결과를 보여 줍니다. 「다시 보기」로 그 미션의 설명·계산을 다시 볼 수 있고, 「그 장소로 가기」로 바로 이동합니다. 점수는 처음 답 그대로입니다.
- **NPC 다시 말 걸기**: 지난 NPC는 미션 다시 보기·설명 다시 듣기를 고를 수 있고, 진행 중인 NPC도 설명을 다시 들을 수 있습니다. 보너스 퀴즈를 맞힌 주민은 문제와 답을 다시 알려 줍니다.
- **복습 퀴즈**: 지나온 미션의 재도전 문제, 가 본 마을 주민 퀴즈, 읽은 용어에서 최대 5문제가 무작위로 나옵니다. 처음 4문제 이상 맞히면 보너스 도토리 5개를 줍니다.

### 조작·화면
- 걷기는 조금 빠르게(칸당 0.155→0.12초), 달리기는 조금 느리게(0.085→0.092초) 바꿨습니다.
- **화면을 눌러 이동**: 누른 곳까지 길을 찾아 걷습니다. 주민·문·표지판을 누르면 그 앞까지 가서 말을 겁니다. 방향키나 조이스틱을 쓰면 바로 멈춥니다.
- **확대 방지**: 지도 화면에서 두 손가락 확대와 두 번 눌러 확대를 막았습니다. 미션 화면은 「가 글자 크게」 버튼과 브라우저 확대를 그대로 쓸 수 있습니다.
- 휴대폰 가로 화면에서 정보창·버튼을 작게 정리했습니다.

### 쉬운 설명·계산기
- 미션마다 「💡 쉬운 말 설명 · 풀이 힌트」를 넣었습니다. 힌트는 정답 대신 풀이 방향만 알려 줍니다. 한국어가 서툰 학생도 읽기 쉽게 짧은 문장으로 썼습니다.
- **🧮 계산기**: 지도와 미션 어디서나 열 수 있습니다. 사칙연산·괄호·%를 계산하며 키보드로도 입력됩니다.
- 「가 글자 크게」 설정은 브라우저에 기억됩니다.

### 재미 요소
- **🛒 꾸미기**: 옷 3종(멜빵바지·후드티·정장)과 털 색 3종을 추가했습니다. 시작 선물로 보너스 도토리 10개를 주어 누구나 바로 꾸밀 수 있습니다.
- **📈 모의 투자 3라운드**: 가상 회사 3곳에 3번 투자해 보며, 소문을 믿거나 한곳에 몰았을 때 결과가 얼마나 흔들리는지 겪어 봅니다. 3라운드는 시장 전체 하락입니다. 📒 기록이나 증권소 까치에게서 시작하며, 처음 끝내면 보너스 도토리 5개를 줍니다. 가상 자료이며 점수와 관계없습니다.
- **충동구매 요정 추격전**: 카드가게 마을에 분홍 하트를 단 요정이 도망다닙니다. 따라가 잡으면 「사기 전에 하루 기다리기」를 알려 주고 보너스 도토리 5개를 줍니다.
- **🏅 도전 과제 6개**: 황금 도토리, 용어 표지판, 주민 퀴즈, 요정 잡기, 모의 투자, 복습 퀴즈. 📒 기록과 수료증에 표시합니다.

### 보너스 도토리 계산
보너스 도토리 = 시작 선물 10 + 보너스 퀴즈 5×맞힌 수 + 황금 도토리 5×찾은 수 + 요정 잡기 5 + 모의 투자 첫 완료 5 + 복습 퀴즈 첫 4문제 이상 5 − 상점 사용액. 미션 도토리(85~160점)와 칭호 구간은 6차와 같습니다.

## 실행과 배포

- 배포 진입 파일은 **index.html**입니다. 원본 이름이 `index(1).html`인 경우 `index.html`로 바꿔 배포합니다. 이번 ZIP의 실제 원본 이름은 이미 `index.html`이었습니다.
- `index.html`, `README.md`, 빈 `.nojekyll`을 함께 제공합니다. 게임 실행 코드는 HTML 한 파일 안에 있습니다. 서버·빌드·설치가 필요하지 않습니다.
- GitHub 저장소 최상위에 파일을 올리고 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.
- Actions의 Pages 배포 작업 성공과 Settings → Pages의 게시 주소를 확인한 뒤 실제 주소에서 시작·저장·재접속을 점검하세요. 단순히 1~2분 기다린 것만으로 배포 성공을 판단하지 않습니다.
- 이번 작업에서는 온라인 게시를 실행하지 않았습니다. `변경·검증 보고서.md`와 검증 자료는 교사용이며 공개 배포에서 제외해도 됩니다.
- 목표 지원 환경: 최근 Chrome·Edge·Safari, Android Chrome, iOS Safari. 이번 환경에서는 실제 브라우저·모바일 검증을 완료하지 못했습니다. 수업 전 아래 체크리스트를 확인하세요.

## 조작과 접근성

- 시작 화면: Tab으로 이동하고 Enter·Space로 버튼 실행. `텍스트 학습으로 시작`을 선택하면 지도 탐색 없이 미션을 진행합니다.
- 지도: 방향키/WASD 이동, Shift 달리기, E·Enter·Space 상호작용. 지도에 초점이 있어야 합니다. Tab으로 화면 버튼에 접근할 수 있습니다.
- 미션 패널: 입력·버튼·링크의 기본 키 동작을 유지합니다. Tab/Shift+Tab은 열린 모달 안에서 순환하고 Escape로 패널을 닫습니다.
- 대화: 계속 버튼 또는 대화 영역에서 Enter·Space로 진행합니다. 선택지는 Tab으로 이동해 실행합니다. 대화 영역에 초점이 있으면 위·아래 키 선택도 가능합니다.
- 엔딩: Tab으로 수료증 보기·계획 고치기 이동, Enter·Space로 실행합니다.
- 모달은 이름·초점 진입·초점 순환·복귀와 배경 inert를 처리합니다. 지도 확대 제한을 제거했고, 움직임 줄이기 설정과 소프트 키보드의 visualViewport를 반영했습니다.
- 대화의 시각적 타자 효과는 화면 읽기 도구에서 숨기고 완성된 문장만 안내합니다.
- 예산 7항목은 원 단위 직접 입력, ±1만 원, 남은 금액 배분을 지원합니다. 완료 시 합계가 교육용 추정 실수령액과 정확히 일치해야 합니다.

## 계획서와 엔딩의 의미

- 월 저축 충족률 = 현재 월 저축 예산 ÷ 세 목표에 필요한 월저축 합계 × 100. 미래 자산의 실제 달성률이 아닙니다.
- 1년·3년·10년 목표는 12·36·120개월로 고정하며, 동시에 별도로 준비합니다. 현재 자산·목표 이자를 제외하고 필요 월저축을 계산합니다. 목표 완료 후 재배분은 계산하지 않습니다.
- 카드·돌발 사건 비용은 기본 장기 전망에 자동 반영되지 않습니다. 비상금도 목표 저축과 분리합니다. 현금흐름 시뮬레이션 확대는 보류했습니다.
- 계획서에서 예산을 다시 입력하면 목표 비교·장기 전망·엔딩·복사 내용은 같은 현재 예산을 사용합니다. 최초 선택·보상 기록은 바뀌지 않습니다.
- 주식 미션(10~20점)이 더해져 정상 완료 미션 점수는 85~160점입니다(5차 75~140점). 칭호 구간은 85~114 `개념 연습 탐험가`, 115~134 `개념 성장 탐험가`, 135~160 `개념 연결 탐험가`입니다. 5차 경계(100·120)에 주식 미션 평균 15점을 더했습니다. 소비 성향이나 재산 수준으로 해석하지 않습니다.
- 사용자 확인에 따라 **첫 응답 기준 유지, 재도전 성과 별도 표시**를 적용했습니다. 재도전은 기존처럼 유사 문제 1회이며 도토리를 추가 지급하지 않습니다.

- 4차 저장(버전 1)은 같은 버튼으로 버전 2를 거쳐 6차로 이전합니다. 아래는 5차부터 유지된 버전 1 이전 규칙입니다.
- 버전 1 저장은 필드 검증 후 시작 화면에서 **원본 보존하고 5차로 가져오기**를 눌러 이전합니다. 원래 키는 유지하고 버전 2의 별도 키에 저장합니다. 4차의 비상금 자동 잔돈을 명시 금액으로 전환합니다. 보험료 변경으로 예산 합계가 달라지므로 현재 계획을 다시 확인하도록 완료 상태를 해제합니다.

## 수업 전 확인

320px·390px 세로, 작은 가로 화면, 200% 확대, 소프트 키보드가 열린 상태에서 대화·선택지·닫기 버튼을 점검하세요. iOS Safari·Android Chrome 실제 기기에서 시작→미션→엔딩→수료증→계획 재편집, 저장 후 재접속, 공용 기기 초기화를 확인하세요. 5차의 실제 화면 검증 상태는 `5차 개발/변경·검증 보고서.md`에 있습니다.

6차 작업에서 데스크톱 브라우저(로컬 서버)로 확인한 것: 오류 없이 시작, 텍스트 학습으로 1~9단계 전체 진행, 주식 미션 오답 → 재도전 → 바구니 선택 → 다음 단계, 계획서 완성·엔딩·수료증(8개 미션 기록), 5차 저장 가져오기 후 주식 미션 → 원래 단계 복귀, 증권소 외관·실내·까치 대화, 375px 폭에서 주식 미션 화면(가로 스크롤 없음). **실제 휴대폰 기기와 지도 모드의 휴대폰 조작은 확인하지 않았습니다.**
