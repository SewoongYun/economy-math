# 다람이의 도토리 숲

스무 살 다람이가 되어 숲 마을을 돌아다니며 월급, 예산, 적금, 복리, 카드, 비상금을 배우고 나만의 재무계획서를 쓰는 도트 RPG입니다. 경제 수학 수업용으로 만들었습니다.

- 약 25~30분 · 휴대폰, 태블릿, PC 브라우저에서 실행
- 설치 없이 웹 주소로 접속
- 진행 상황은 학생 각자의 브라우저에 저장되며 서버로 전송되지 않음

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 **Public**으로 만듭니다.
2. 이 폴더 안의 파일(`index.html`, `README.md`, `.nojekyll`)을 저장소 맨 위에 올립니다. 폴더째로 올리지 않습니다.
3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 저장합니다.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 접속합니다.

## 수업 전 확인

- 인터넷 연결이 필요합니다. 도트 글꼴을 인터넷에서 불러오며, 연결이 안 되면 기본 글꼴로 보입니다.
- 소리는 시작 버튼을 누른 뒤 나옵니다. 아이폰은 무음 스위치가 켜져 있으면 소리가 나지 않을 수 있습니다.
- 오른쪽 위 🔊는 효과음, 🎵는 배경음악을 끄고 켭니다.
- 금액과 세율은 수업용 2027년 가정이며, 소득세는 근사치입니다.
